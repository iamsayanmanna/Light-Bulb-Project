💡 Light Bulb Project


A simple and interactive Light Bulb Web Project built using HTML, CSS, and JavaScript.
This project demonstrates how to toggle a light bulb on and off with a user‑friendly design.

🚀 Features
Toggle the bulb ON and OFF

Clean and responsive UI

Simple JavaScript logic for interaction

Beginner‑friendly project for web development practice

🛠️ Technologies Used
HTML5 for structure

CSS3 for styling

JavaScript for interactivity

📂 Project Structure
Light-Bulb-Project/
│
├── index.html        # Main HTML file
├── style.css         # Stylesheet
├── script.js         # JavaScript logic
└── Light bulb.mp4    # Demo video (optional)
